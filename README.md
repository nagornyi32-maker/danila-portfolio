# Данила Нагорный — портфолио

Сайт нейрокреатора Данилы Нагорного. Связь: https://t.me/DanilaNS

`index.html` содержит страницу, стили и встроенный шрифт. `app-v2.js` отвечает за просмотр изображений и видео. В `assets-*.zip` находятся изображения, превью и видео. При публикации GitHub Actions распаковывает их и отправляет готовый сайт в GitHub Pages.

Для запуска локально распакуйте все архивы в одну папку с `index.html`.

Работы в портфолио принадлежат их правообладателям. Публикация в этом репозитории не предоставляет лицензию на повторное использование работ. Шрифт Manrope распространяется по лицензии в `OFL.txt`.
